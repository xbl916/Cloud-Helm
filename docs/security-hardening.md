# 安全修复与接入说明

本次代码修复不要求停止业务容器或释放 GPU。部署前保留数据库和 Agent 状态文件；新版本准备、测试完成后再切换管理服务。已有业务容器与 Agent 凭据无需重新创建。

## 业务容器绑定

业务上报中的 `container_id` 只能与服务实例已有绑定一致；不能用上报令牌建立绑定或改绑其他容器。省略该字段仍然保留已有绑定，不影响业务数和健康状态上报。

新实例使用 Agent 观察到的 Docker 标签 `cloudhelm.service_id`、`cloudhelm.instance_id` 建立关联。Agent 是受信任的节点管理组件，其凭据应由节点管理员保管。已有人工建立的绑定不会在升级中自动删除；上线前管理员应核对各服务实例的节点、容器是否正确。旧客户端依赖首次上报 `container_id` 建立关联时，需先完成标签绑定，否则会收到 403。若添加标签需要重建业务容器，应安排在正常版本切换中进行，不应为这次安全升级直接停止 GPU 业务。

## Kubernetes 工作负载绑定

只有平台管理员能修改 `provider`、`namespace`、`workload_kind`、`workload_name`、`acs_container_name`。服务操作员仍可调整容量、阈值和伸缩策略；服务发布权限仍可发布已绑定工作负载。前端同步禁用非管理员的绑定字段。

平台的 Kubernetes 凭据还应使用最小 RBAC 范围。既有绑定不做自动修改，上线前应核对实际目标。

## Agent 注册和恢复

共享注册令牌只允许新增节点。已有 `agent_key` 重复注册返回 409，原节点凭据保持有效。日常升级继续保留 `/data/agent-state.json`。

丢失独立凭据时，平台管理员可调用 `POST /api/v1/nodes/{node_id}/agent-token/rotate`。该接口需要管理员登录，并遵循现有 CSRF/Bearer 认证规则；返回 `agent_key`、`node_id`、`node_token`，令牌仅在响应中显示，旧凭据立即失效，并记录不含令牌的审计事件。

将响应的三个字段安全写入该节点的 `agent-state.json`，文件权限设为 `0600`，然后只重启 Agent 以加载新凭据。不要把令牌放进日志、工单或版本库，不需要重启业务容器。

## 企微成员生命周期

新增接收地址：`https://平台域名/api/v1/auth/wecom/events`。

1. 在服务端配置 `CLOUDHELM_WECOM_CALLBACK_TOKEN` 与 `CLOUDHELM_WECOM_CALLBACK_AES_KEY`，两项必须同时存在。AES key 使用企微后台的 43 字符 EncodingAESKey。
2. 新版本服务准备完成后切换启动，在企微后台可接收通讯录变更事件的配置入口填写上述接收地址、同一 Token 和 EncodingAESKey，并完成 URL 验证。需确认配置对应的应用/通讯录权限能接收到目标成员事件；普通登录配置不会自动启用通讯录同步。
3. 使用专门的测试成员验证：先登录平台，再在企微删除该成员，确认平台审计出现 `wecom.directory.disable`，原会话下一次请求返回 401。不要用当前唯一管理员测试删除。
4. 重新创建相同 UserId 后，平台旧账号仍应保持停用。管理员核实身份、检查旧角色及授权后，才可手动恢复；事件绝不会自动创建平台用户或启用账号。

回调验证企业微信消息签名、AES-CBC 密文、PKCS#7 填充及接收企业；请求签名时间允许前后 10 分钟，限制请求大小并拒绝 DTD/实体 XML。删除成员、新建成员命中已有平台账号，以及更新事件中 Status=2/4 时，会停用本地账号并撤销其会话。事件摘要入库，重复投递不会再次覆盖管理员后续的恢复操作，摘要保留 30 天。

必须先完成企微后台接入并确认事件送达，这项同步才生效。回调中断、漏投或尚未接入时，不能保证企微删除后即时撤权；离职流程仍应同步停用平台账号。该实现不宣称能在缺少事件的情况下区分两个相同 UserId 的不同人员。

当前只处理成员删除、创建和明确的禁用状态事件；不把普通资料更新作为账号恢复依据。企微应用可见范围变化不等同于这些事件，尚不提供全量通讯录对账。

## 企微认证地址

生产环境强制 `wecom_api_base` 使用 HTTPS；默认仍为 `https://qyapi.weixin.qq.com`。带用户名、密码、查询串或 fragment 的企微 API/扫码授权地址会在配置加载时被拒绝。开发测试环境仍可使用 HTTP 模拟服务。

## 数据库与验证

新增 `wecom_event_receipts` 表和 `0016_wecom_event_receipts` 迁移记录。沿用项目启动时的 SQLite 自动备份与增量迁移，不删除旧数据。PostgreSQL 应继续按既有流程备份。

回归测试位于 `tests/test_security_regressions.py`，覆盖跨容器关联、工作负载越权、注册覆盖、管理员恢复节点凭据、HTTPS 配置与加密回调。真实企微事件送达需要在上述配置完成后验证。
